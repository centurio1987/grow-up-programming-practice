# 쉽게 이해하는 알고리즘 · 자료구조 — 실습

책 「쉽게 이해하는 알고리즘」과 「쉽게 이해하는 자료구조」의 실습 파일입니다. 책의 각 장 끝 「실습」 절이 가리키는 파일이
여기 있어요. 학습자가 직접 채울 빈 함수 파일(스텁)과, 채운 답을 채점하는 시험이 짝을 이룹니다.

## 준비

[Bun](https://bun.sh) 이 필요합니다. 저장소를 받은 폴더에서 한 번 설치합니다.

```bash
bun install
```

## 실습하는 법

1. 책의 실습 절에서 풀 파일을 찾습니다. 예를 들어 `practice/algorithms/sorting/countingSort/countingSort.ts` 입니다.
2. 파일 안의 `throw new Error("Not implemented")` 를 지우고 구현합니다.
3. 같은 폴더의 시험을 실행합니다.

```bash
bun test practice/algorithms/sorting/countingSort/countingSort.test.ts
```

알고리즘 실습은 `practice/algorithms/` 에, 자료구조 실습은 `practice/data-structures/` 에 있습니다. 자료구조 실습은
스텁 파일 머리말에 적힌 계약(그 자료구조가 지켜야 할 동작)을 지키는지 계약 시험이 확인해요. 계약 시험이 쓰는 채점기는
`practice/data-structures/_contract/` 에 있습니다.

## 처음엔 시험이 실패합니다

스텁은 채우기 전까지 `Not implemented` 오류를 던지게 만들어 두었습니다. 그래서 받은 그대로 `bun test` 를 실행하면 시험
대부분이 실패해요. 고장이 아니라 정상입니다. 구현한 파일의 시험부터 하나씩 통과로 바뀝니다.

전체가 아니라 푸는 파일의 시험만 실행하면 결과를 읽기 쉽습니다.

## 주석에 보이는 낯선 경로

일부 파일의 주석에는 `docs/…` · `guides/…` · `KAN-…` 같은 표기가 있습니다. 이 실습을 만든 원본 저장소의 문서와 작업
기록을 가리키는 자리라서 이 저장소에는 없어요. 실습을 푸는 데에는 필요하지 않습니다.

## 이 저장소에 대해

이 저장소는 원본 저장소에서 내보낸 결과입니다. 여기서 직접 고친 내용은 다음 내보내기 때 덮어쓰여요. 고칠 점을 찾으면
이슈로 알려 주세요.
